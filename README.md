# لقطة | LOQTAH — متجر تجريبي
متجر عربي RTL بتصميم أبيض وبنفسجي، React + Vite، وخادم Express.

## التشغيل
يتطلب Node.js 20 أو أحدث:
```bash
npm install
cp .env.example .env
npm run dev
```
على Windows PowerShell استخدم `Copy-Item .env.example .env`.
المتجر: http://localhost:5173
فحص API: http://localhost:4000/api/health

## الموجود
- واجهة متجاوبة، بحث وفلاتر
- بطاقات منتجات تجريبية، مفضلة وسلة
- نموذج طلب COD
- API تجريبي يتحقق من البيانات ويعيد رقم طلب
- ألوان وهوية لقطة LOQTAH

## قبل الإطلاق الحقيقي
- المنتجات والأسعار والتقييمات تجريبية ولا تمثل كتالوج نينجا سيلرز.
- الطلبات مخزنة في ذاكرة الخادم وتختفي عند إعادة التشغيل؛ أضف PostgreSQL.
- لا يوجد ربط فعلي بنينجا سيلرز. اطلب توثيق API ومفاتيح رسمية واختبر في بيئة تجريبية.
- لا تعرض بيانات العملاء أو استعلام الطلبات دون مصادقة وصلاحيات.
- أضف rate limiting وHTTPS وسجلات آمنة ونسخًا احتياطية وسياسات خصوصية وشحن وإرجاع.
- تحقق من متطلبات الترخيص والتعاقد والتحصيل قبل استقبال طلبات حقيقية.
- احسب الشحن والضرائب ورسوم المورد قبل تفعيل الأسعار.
